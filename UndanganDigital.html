PENYIMPANAN GAMBAR

Cara Membuat ImgBB API Key

API Key digunakan oleh semua fitur Upload Gambar di Admin Panel. Cukup isi satu kali pada kartu ImgBB di tab Cover.

1
Buka halaman API ImgBBTekan tombol di bawah untuk membuka halaman resmi ImgBB.
2
Login atau buat akunMasuk ke akun ImgBB, lalu buka bagian API dan buat/salin API Key.
3
Tempel API Key di siniKembali ke Admin Panel → tab Cover → kartu ImgBB → masukkan key lalu tekan Simpan.
Key disimpan di IndexedDB browser. Semua upload gambar menggunakan key yang sama dari kartu ImgBB di tab Cover.
